# To Do

Aplicação em Next.js para cadastrar e gerenciar tarefas.

Dá para adicionar uma tarefa, marcar como concluída ou pendente, excluir, filtrar (todas, pendentes e concluídas) e ver quantas tarefas estão cadastradas. As tarefas ficam salvas no navegador.

## Como rodar

```bash
npm install
npm run dev
```

Abre http://localhost:3000
